# contracts/

Kontrak mesin-baca untuk aplikasi sampel:

- `openapi.yaml` - REST API (OpenAPI 3.1) - dibuat Fase 0b
- `asyncapi.yaml` - WebSocket events (AsyncAPI 3) - dibuat Fase 0c
- `.spectral.yaml` - aturan lint kontrak
- `examples/` - contoh JSON untuk quicktype (model Dart dibuat pemilik proyek)
- `scripts/` - skrip pemeriksaan cakupan
